# 集団指導の資料（介護保険・保育所等）：直した文の照合（2回目）の決まり

1回目の照合で不合格になった文を、照合係の指摘に沿って直しました。直した文が原文どおりかを、1文ずつ確かめてください。
判断の基準は 1回目と同じです（RULES_verify_k.md の「1文ずつ確かめること」1〜8）。迷ったら不合格にしてください。

## 入力
- 直した文: `r2/<組>.json` の `stmts[]`。各要素は `chunk`（かたまり）・`k`（項目の鍵）・`t`（見出し）・`to`（文の位置）・
  `text`（直した文）・`before`（直す前の文）・`why_before`（1回目に不合格になった理由）
- 原文: `r2/<組>-source.json` の `items[]`（`chunk` と `k` で引く。`text` がその見出しの本文。`[p.N]` はPDFのNページ目。
  `images` は文字が取れないページの画像で、Read ツールで開いて読む。章の項目の text は章の頭の部分だけなので、章の残りは同じ chunk の「k が章の鍵:」で始まる項目を見る。そこにないときは、同じフォルダの vchunks/<chunk>.json を開いて見る）

## 確かめること
- `text` が、その項目の原文で裏づけられるか（1回目の基準1〜8）。
- 1回目に指摘された問題（`why_before`）が直っているか。直っていなければ不合格。

## 出力
指示されたパスに JSON を1つ書く:
```
{"batch": "…", "results": [
  {"chunk": "k05", "k": "houmon:1:12", "to": "points.1", "ok": true},
  {"chunk": "k05", "k": "houmon:1:3", "to": "gist", "ok": false, "why": "…", "quote": "原文の該当箇所"}
]}
```
- `stmts` のすべての文について1行ずつ出す。不合格には why と quote を必ず書く。
- WebFetch・WebSearch は使わない。指示されたパス以外にファイルを書かない（作業用のスクリプトは自分専用の名前のフォルダに置き、終わったら消す）。ほかの照合係の結果を読まない。
