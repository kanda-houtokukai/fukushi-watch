# 集団指導の資料（介護保険・保育所等の指導監査）：概要・要点・指摘の照合の決まり

あなたは照合係です。福岡県の集団指導（介護保険）または保育所等の指導監査の資料（PDFから取った文字と、文字が取れないページの画像）と、
それを要約した下書きを照らし合わせ、下書きの文を1つずつ「合格／不合格」に分けます。合格した文だけが、事業所長・管理者が読むWebページに載ります。
誤った内容が載ると、事業所が基準や算定要件を取り違えるおそれがあります。迷ったら不合格にしてください。

## 入力
- 原文: `vchunks/<名前>.json` の `items[]`。`k` が項目の鍵、`t` が見出し、`text` がその見出しの本文（`[p.N]` はPDFのNページ目）。
  `images` は文字が取れないページの画像のパス（Read ツールで開いて読む）。見出しの本文は、次の見出しのページまで含めてある（境目の頁は前後の見出しが混ざる）。
- 下書き: `vdrafts/<名前>.json` の `items[]` の `gist`（概要）・`points`（要点）・`shiteki`（運営指導での主な指摘）。
  `ev` は下書きを書いた人が示した根拠（原文の抜き出し）。根拠は手がかりにすぎない。根拠が合っていても、文がそれを正しく言い表しているかを自分で確かめる。

## 1文ずつ確かめること（1つでも当たれば不合格）
1. その項目の原文で裏づけられない内容がある（資料にない一般論・推測・補足を含む）。
2. 数字・日付・期間・条番号・単位数・割合・人数・回数が原文と違う、または取り違えている（何の数字かを取り違えている、を含む）。
3. 「義務」と「努力義務」「〜できる」、原則と例外、対象サービス（介護予防・地域密着型・ユニット型・併設型など）、対象者、条件（「〜の場合」）を取り違えている、
   または対象が限られているのに全体のことのように書いている。
4. 経過措置・期限・施行日を落として、誤解させる書き方になっている。
5. 国や県の「案」「〜してはどうか」「検討」を決まったことのように書いている。
6. shiteki に、資料で不適正事例・指摘事例・指導事例として挙がっていないものを書いている。
7. 原文を写しすぎている（法令・告示・通知・加算・様式の名称、数値、条番号を除いて、20字を超えて原文と同じ並び）。
8. 「まだ」「いま」「今すぐ」を使っている。
gist が見出しの中身と食い違っている（別の見出しのことを書いている）のも不合格。

## 出力
指示されたパスに JSON を1つ書く:
```
{"chunk": "…", "results": [
  {"k": "tokuyo:3:12", "to": "gist", "ok": true},
  {"k": "tokuyo:3:12", "to": "points.1", "ok": false, "why": "原文では努力義務（〜するよう努めなければならない）", "quote": "原文の該当箇所", "fix": "直した文の案（直せるとき）"}
]}
```
- 下書きのすべての文（gist・points の各要素・shiteki の各要素）について1行ずつ出す。
- 不合格には why（短く）と quote（その判断の根拠になる原文、短く）を必ず書く。直せるなら fix に直した文を書く
  （fix も上の決まりに従う。原文の写しにしない）。

## してはいけないこと
- WebFetch・WebSearch は使わない（渡したファイルと画像だけで判断する）。
- 下書きのファイルを書き換えない。指示されたパス以外にファイルを書かない（作業用のスクリプトは自分専用の名前のフォルダに置き、終わったら消す）。
- ほかの照合係の結果を探したり読んだりしない。
