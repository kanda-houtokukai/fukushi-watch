# 集団指導（介護保険）の資料：見出しを選び、見出しごとの「概要・要点・指摘」を作る決まり

## 何のためのものか
福岡県が介護サービス事業所向けに掲載した「令和8年度 集団指導（介護保険）」の資料（PDF）を、事業所長・管理者が
Webページ上で見返せるようにする。ページでは章を開くと見出しが並び、見出しを押すとその「概要・要点・運営指導での主な指摘」が開く。
読む人は、自分の事業所が基準・算定要件を満たしているか、何を確かめればよいかを知りたい。

## 入力
かたまりのファイル（JSON）。`items` の各項目が1つの章（長い章は part に分かれている）:
- `k` … 項目の鍵（そのまま出力に使う）、`doc` … 資料、`t` … 章の題、`p`／`p_end` … PDFのページの範囲
- `part`／`parts` … 長い章を分けたときの何番目か（part 2 以降は前の part の続き）
- `text` … 本文（PDFから取った文字。`[p.N]` はそこからPDFのNページ目）。表の文字は列が崩れていることがある。
- `images` … 文字が取れないページの画像のパス。**Read ツールで画像を開いて中身を読む**（本文に「画像 … を見る」とある頁）。
- `mode` … "fixed"＝見出しが決まっている（`heads` に {t, p}）／"free"＝見出しを自分で選ぶ
- `slides` … true ならスライドの資料（各ページの題がそのページの見出し）

## 出力
1つの JSON ファイル（指示されたパス）。形:
```
{"chunk": "k05", "items": [
  {"k": "houmon:2",
   "chapter": {"gist": "…", "points": ["…"], "shiteki": [], "ev": [{"to": "gist", "p": 50, "q": "原文の抜き出し"}, …]},
   "heads": [
     {"t": "（１）事業の基本方針", "p": 50, "gist": "…", "points": ["…"], "shiteki": ["…"], "ev": [{"to": "gist", "p": 50, "q": "…"}, …]},
     …
   ]}
]}
```
- 入力の `items` のすべての `k` を、漏れなく同じ順で出す。
- `chapter` は part が 1 のときだけ書く（part 2 以降は `"chapter": null`）。
- `ev`（根拠）は、gist・points の各要素・shiteki の各要素のそれぞれに1つ以上。`to` は "gist"・"points.0"・"shiteki.1" の形。
  `p` はその抜き出しがあるPDFのページ番号（`[p.N]` で数える）。`q` は**原文の連続した部分をそのまま**10〜60字
  （改行と空白は取り除いてよい。それ以外は1字も変えない。全角・半角も原文のまま）。画像から読んだときは、画像の文字をそのまま書き、
  `"img": true` を付ける。`ev` は照合にだけ使い、ページには出さない。

## 見出しの選び方（mode が "free" のとき）
- 県の資料が付けている見出しの行から選ぶ（例:「（１）事業の基本方針」「２ 設備に関する基準」「（５）夜勤職員配置加算」「第２ 不適正事例」「Ｑ＆Ａ」）。
  **自分で見出しを作らない。** `t` は、その見出しの行の文字を原文のまま写す（空白は詰めてよい・60字まで。長い見出しは途中まででよい）。
  `p` はその見出しの行があるPDFのページ。見出しは出てくる順に並べる。
- 1つの話題としてまとまる単位を選ぶ。目安は1見出しあたり1〜5ページ、章あたり3〜30個。
  **表の行・箇条書きの項目・加算の区分（Ⅰ）（Ⅱ）ごとの行・単位数の行・例示の行は見出しにしない**（それらは要点に入れる）。
  同じ番号の付け方が入れ子になっているとき（（１）の中にまた（１）がある）は、上の段を選ぶ。
- 章の頭から最初の見出しまでの本文は、章の要点（`chapter.points`）に入れる。
- 章が短い（3ページ程度まで）か、中に見出しがない場合は、`heads` を空にして、章の要点で全体をまとめる（points 最大8個）。
- スライドの資料（`slides`）は、内容のまとまり（スライドの題が同じか続くもの）を見出しにする。題がない頁は前の見出しに含める。
- Ｑ＆Ａの章は、問ごとに見出しにしない。Ｑ＆Ａのまとまり（「〇〇について」「加算関係」など資料の区切り）を見出しにし、要点に主な問と答えを短く書く。
- 国の通知・告示の写し（「医療保険と介護保険の給付調整」「〜について（通知）」など）は、通知の中の見出し（第１、１、（１）など）の上の段を見出しにする。

## 見出しの扱い（mode が "fixed" のとき）
- `heads` の {t, p} をそのまま同じ順で出し、それぞれに概要・要点・指摘を書く（見出しを足したり消したりしない）。

## 書き方
- **gist（概要）**: 1〜2文・60〜140字・です・ます。その見出し（章）が何を定めているか・何を説明しているかを、事業所の側から書く
  （例：「サービス提供の記録に何を書き、利用者から何を受けるかの決まりです。」）。
- **points（要点）**: 0〜6個（見出しのない章は最大8個）。常体で短く（1つ80字以内）。基準・要件・手続き・期限・数値・単位数・
  してはいけないこと・届出先など、事業所が確かめる具体を書く。資料に書かれていない一般論や推測は書かない。本文がほとんどない見出しは points を空にしてよい。
- **shiteki（運営指導での主な指摘）**: 資料に「不適正事例」「指摘事例」「指導事例」「主な指摘」「運営指導における不適正事例」「〜の誤り」などとして
  挙がっているものだけ。最大5個。なければ空の配列。
- **写さない**: 資料の文を長く写さない。自分の言葉で短くまとめる。20字を超えて原文とそっくり同じ並びにしない
  （ただし法令・告示・通知の名称、加算・減算の名称、条番号、様式名、数値、期日はそのまま書く）。
- **正確に**: 数字・日付・条番号・単位数・割合は原文どおり（全角を半角にするのは可）。
  「義務」と「努力義務」、「〜しなければならない」と「〜するよう努める」、「〜できる」を区別する。
  対象のサービスが限られている内容は対象を書く（例「（介護予防も同様）」「ユニット型のみ」「地域密着型」「併設型」「空床利用型」）。
  経過措置や「令和◯年◯月◯日までの間」は必ず書く。「〜してはどうか」「〜を検討」のような案を、決まったことのように書かない。
  原文で読み取れないこと（表の列が崩れて対応が分からない など）は書かない。令和7年度の資料は、令和7年度の資料のとおりに書く。
- **言葉づかい**: 「まだ」「いま」「今すぐ」「いますぐ」は使わない。「○○、○○。」のような体言止めの二句や、物語調・宣伝調は使わない。
  記号の多用・太字・絵文字は使わない。「〜について説明しています」だけの中身のない文で終わらせない。
- 本文が図だけ・様式だけ・空に近い見出しは、gist に「◯◯の様式（記入例）です。」のように何があるかを書き、points は空でよい。

## してはいけないこと
- WebFetch・WebSearch・外部への取得はしない（渡したファイルと画像だけで作る）。
- 指示されたパス以外にファイルを書かない（作業用のスクリプトを作るなら、自分専用の名前のフォルダに置き、終わったら消す）。
