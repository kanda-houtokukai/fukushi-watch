# 集団指導の資料：直した文の照合（2回目）の決まり

1回目の照合で不合格になった文を、照合係の指摘に沿って直しました。直した文が原文どおりかを、1文ずつ確かめてください。
判断の基準は 1回目と同じです（/tmp/claude-0/-home-claude/d3e68208-19dc-5758-b37a-438c236beec9/scratchpad/syudan/RULES_verify.md の「1文ずつ確かめること」1〜8）。
迷ったら不合格にしてください。

## 入力
- 直した文: `round2/stmts.json` の `stmts[]`。各要素は
  `k`（項目の鍵）・`t`（見出し）・`to`（文の位置。"gist"・"points.2" など）・`text`（直した文）・`before`（直す前の文）・`why_before`（1回目に不合格になった理由）
- 原文: `round2/source.json` の `items[]`（`k` で引く。`text` がその見出しの本文。`[p.N]` はPDFのNページ目）

## 確かめること
- `text` が、その項目の原文で裏づけられるか（1回目の基準1〜8）。
- 1回目に指摘された問題（`why_before`）が直っているか。直っていなければ不合格。

## 出力
指示されたパスに JSON を1つ書く:
```
{"chunk": "round2", "results": [
  {"k": "gh:12", "to": "points.1", "ok": true},
  {"k": "gh:12", "to": "gist", "ok": false, "why": "…", "quote": "原文の該当箇所"}
]}
```
- `stmts` のすべての文について1行ずつ出す。不合格には why と quote を必ず書く。
- WebFetch・WebSearch は使わない。指示されたパス以外にファイルを書かない（作業用のスクリプトは自分専用の名前のフォルダに置き、終わったら消す）。ほかの照合係の結果を読まない。
