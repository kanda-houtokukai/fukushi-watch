# 集団指導の資料：見出しごとの「概要・要点・指摘」を作る決まり

## 何のためのものか
福岡県が障がい福祉サービス事業所向けに配った「令和8年度 集団指導」の説明資料（PDF）を、事業所長・管理者が
Webページ上で見返せるようにする。ページでは見出しを押すと、その見出しの「概要・要点・運営指導での主な指摘」が開く。
読む人は、自分の事業所が基準を満たしているか・何を確かめればよいかを知りたい。

## 入力
チャンクのファイル（JSON）。`items` の各項目が1つの見出し:
- `k` … 項目の鍵（そのまま出力に使う）
- `kind` … "chapter"（章）／"item"（章の中の見出し）／"doc"（見出しのない短い資料）
- `t` … 見出し、`chap` … 属する章、`p`／`p_end` … PDFのページ
- `text` … その見出しから次の見出しまでの本文（PDFから取った文字。`[p.N]` はそこからPDFのNページ目）。
  表の文字は列が崩れていることがある。図の中の文字が混ざることもある。
- `chapters[k].subs` … その章に属する見出しの一覧（章の概要を書くときの手がかり）

## 出力
1つの JSON ファイル（指示されたパス）。形:
```
{"chunk": "c01-common", "items": [
  {"k": "common:3",
   "gist": "1〜2文の概要（です・ます）",
   "points": ["要点（常体・1つ80字以内）", ...],
   "shiteki": ["運営指導での主な指摘（資料に書かれているものだけ）", ...],
   "ev": [{"to": "gist", "p": 3, "q": "原文の抜き出し"}, {"to": "points.0", "p": 4, "q": "…"}, ...]}
]}
```
- 入力の `items` のすべての `k` を、漏れなく同じ順で出す。
- `ev`（根拠）は、gist と points の各要素・shiteki の各要素のそれぞれに1つ以上。`to` は "gist"・"points.0"・"shiteki.1" の形。
  `p` はその抜き出しがあるPDFのページ番号（`[p.N]` で数える）。`q` は**原文の連続した部分をそのまま**10〜60字
  （改行と空白は取り除いてよい。それ以外は1字も変えない。全角・半角も原文のまま）。`ev` は照合にだけ使い、ページには出さない。

## 書き方
- **gist（概要）**: 1〜2文・60〜140字・です・ます。その見出しが何を定めているか・何を説明しているかを、事業所の側から書く
  （例：「サービス提供の記録に何を書き、利用者から何を受けるかの決まりです。」）。
- **points（要点）**: 0〜6個（章で配下の見出しがないものは最大8個）。常体で短く。基準・要件・手続き・期限・数値・してはいけないこと・
  届出先など、事業所が確かめる具体を書く。資料に書かれていない一般論や推測は書かない。本文がほとんどない見出しは points を空にしてよい。
- **shiteki（運営指導での主な指摘）**: 資料に「指摘事例」「指導事例」「指摘事項」「主な指摘」「不適切な事例」「こんな事例があります」などとして
  挙がっているものだけ。最大5個。なければ空の配列。
- **章（kind "chapter"）**: gist は章全体で何を扱うか（`chapters[k].subs` も見て書く）。points は章のはじめの本文に書かれた要点だけ
  （本文が短ければ空）。配下に見出しがない章は、その章の本文全体を要約する（points 最大8個）。
- **写さない**: 資料の文を長く写さない。自分の言葉で短くまとめる。20字を超えて原文とそっくり同じ並びにしない
  （ただし法令・告示の名称、加算・減算の名称、条番号、様式名、数値、期日はそのまま書く）。
- **正確に**: 数字・日付・条番号・単位数・割合は原文どおり（全角を半角にするのは可）。
  「義務」と「努力義務」、「〜しなければならない」と「〜するよう努める」、「〜できる」を区別する。
  対象のサービスが限られている内容は、対象を書く（例「＜就A＞」「入所のみ」「児発・放デイ」）。
  経過措置や「令和◯年◯月◯日までの間」は必ず書く。「〜してはどうか」「〜を検討」のような案や国の検討中の内容を、決まったことのように書かない。
  原文で読み取れないこと（表の列が崩れて対応が分からない など）は書かない。
- **言葉づかい**: 「まだ」「いま」「今すぐ」「いますぐ」は使わない。「○○、○○。」のような体言止めの二句や、物語調・宣伝調は使わない。
  記号の多用・太字・絵文字は使わない。「〜について説明しています」だけの中身のない文で終わらせない。
- 本文が図だけ・様式だけ・空に近い見出しは、gist に「◯◯の様式（記入例）です。」のように何があるかを書き、points は空でよい。

## してはいけないこと
- WebFetch・WebSearch・外部への取得はしない（渡したファイルだけで作る）。
- 指示されたパス以外にファイルを書かない。
