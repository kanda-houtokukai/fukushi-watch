# 監視対象台帳（sources.md）

福祉情報ウォッチが巡回する情報源の正本。**この表がP1以降の実装の入力になる。**

## 運用ルール

- **P0時点では「器だけ」**。URLの調査・確定は **P1（まず1源だけ）** と **P4（残り4源）** で行う。
- 1源 = 1行。行の追加・削除・状態の変更は、必ずこのファイルへ反映してから実装に渡す。
  **P4以降は、監視源の増設はこの表に1行足すだけで済む状態にする**（コード側を触らない）。
- **確定済みの行は承認なしに書き換えない**（CLAUDE.md「触ってはいけない場所」）。
- 状態の語彙: `URL未確定` → `URL確定` → `巡回方法確定` → `巡回中` → `停止中`
- **巡回方法の列には `scripts/crawl.js` のパーサ名を書く**（例: `cfa-cards`）。
  `crawl.js` は状態が「巡回中」の行だけを巡回する。新しい構造の源を足すときは
  パーサを1つ実装し、その名前をこの列に書く。
- **既定分野の列（P36・任意）**: 源そのものが分野を持つ場合（介護福祉士会=高齢 等）に書く。
  分野判定が「共通」に落ちた項目だけ、この分野へ倒す（判定の優先順は
  タイトル語彙・AI判定 ＞ 全分野向けの例外（虐待防止・BCP・感染症等は共通のまま）＞ 既定分野）。
  語彙は 保育/障害/高齢/児童 のみ・複数は「・」区切り。**空欄＝既定なし**（研修センターの
  ように全分野を扱う源は空欄にする）。語彙外の値は起動時にエラーで止まる（サイレント破損の禁止）。
- **表示名の列（任意・P44）**: 画面の団体欄に出す名前。**空欄＝源の名前をそのまま使う**。
  源の名前は識別キー（既定分野の名前引き・funder生成の材料）なので変えてはならない。
  表示だけを変えたいときはこの列を直す。
  ⚠️**新しい列は必ず表の「最後」に足す**——`crawl.js` は既定分野を `cells[7]`・表示名を
  `cells[8]` の位置で読む。左や途中に挿入すると読み取りが1つずれ、語彙外エラーか静かな誤判定になる。
- **PDF併読の3列（任意・P43）**: 締切が本文でなくリンク先PDFにしか無い源
  （介護福祉士会・社会福祉士会型）のための列。位置は `cells[9]`／`[10]`／`[11]`。
  部品は `scripts/pdftext.js`（機械確認は `scripts/pdftext-check.js`）。
  1. **PDFリンクの目印**: 個別ページで読むべきPDFを選ぶ手掛かり（アンカー文字列の
     部分一致）。1ページに複数のPDF（全ページ共通のバナー・様式類）が並ぶため必須。
     **空欄＝PDF併読しない**（既定動作）。
  2. **ブロックの区切り語**: 1つのPDFに複数の研修が載る場合の区切り
     （例:「開催要綱」）。**空欄＝PDF全体を1ブロック**として扱う（1PDF=1研修型）。
  3. **締切の表記パターン**: 締切を示す目印の文字列（例:「《 締 切 》」）。
     照合は全半角・空白のゆらぎを吸収して行う。⚠️《 》のような囲みごと指定する——
     裸の「締切」にすると「定員になり次第締め切ります」等の平文を誤検出する。
  値を入れるのは区切り②（kenshu.js への接続時）。区切り①では列だけを用意した。
- **開催の要点の2列（任意・P46）**: 研修の画面に「▽ 開催の要点」（畳んだ展開）を出すための列。
  位置は `cells[12]`／`[13]`。**空欄＝要点を出さない**（既定動作）。
  1. **項目の囲み方**: 項目名を囲む記号2文字（例「《 》」）。この囲みの中にある項目だけを
     **原文のまま**切り出す。⚠️説明の段落は囲みの外にあるので構造上入らない
     （本文は複製しない・報道源と同じ原則）。
  2. **要点として出す項目名**: 「・」区切り・**この順で表示**する。
     ⚠️取れなかった項目は画面に「記載なし」と出す。空欄にすると「費用なし」「定員なし」と
     誤読される（実測: #484 は参加費の記載自体が無い）。
  ⚠️**最後に来る項目は指定しても取れない**（値の終わりを決められず、次の研修の見出しや
  ページの注意事項まで飲み込むため。実測で締切1,762字・備考は7件すべてが巻き込み）。
  f-kaigo では締切・備考が末尾なので、締切は既存の締切欄に譲り、備考は出していない。
