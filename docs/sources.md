# 監視対象台帳（sources.md）

福祉情報ウォッチが巡回する情報源の正本。**この表がP1以降の実装の入力になる。**

## 運用ルール

- **P0時点では「器だけ」**。URLの調査・確定、巡回方法の決定は **P1** で行う。
- 1源 = 1行。行の追加・削除・状態の変更は、必ずこのファイルへ反映してから実装に渡す。
- **確定済みの行は承認なしに書き換えない**（CLAUDE.md「触ってはいけない場所」）。
- 状態の語彙: `URL未確定` → `URL確定` → `巡回方法確定` → `巡回中` → `停止中`

## 各源の補足（P1で埋める）

- **こども家庭庁**: 児童分野の一次情報源。対象ページ（新着・報道発表・通知等）のどれを見るかはP1で確定。
- **厚生労働省**: 障害・介護分野の一次情報源。対象ページの粒度をP1で確定。
- **WAM NET**: 行政情報の集約先。一次情報への導線として使うか、それ自体を監視するかをP1で判断。
- **福岡県**: 法人所在地の自治体情報（福智町・県）。市町村レベルまで広げるかはP1で判断。
- **報酬改定関連**: 報酬改定ナビ（kanda-houtokukai/houshu-navi）と情報源が重なる可能性がある。
  重複監視にならないよう、P1で houshu-navi 側の扱いと突き合わせる。
