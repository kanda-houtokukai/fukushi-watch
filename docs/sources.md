# 監視対象台帳（sources.md）

福祉情報ウォッチが巡回する情報源の正本。**この表がP1以降の実装の入力になる。**

## 運用ルール

- **P0時点では「器だけ」**。URLの調査・確定は **P1（まず1源だけ）** と **P4（残り4源）** で行う。
- 1源 = 1行。行の追加・削除・状態の変更は、必ずこのファイルへ反映してから実装に渡す。
  **P4以降は、監視源の増設はこの表に1行足すだけで済む状態にする**（コード側を触らない）。
- **確定済みの行は承認なしに書き換えない**（CLAUDE.md「触ってはいけない場所」）。
- 状態の語彙: `URL未確定` → `URL確定` → `巡回方法確定` → `巡回中` → `停止中`
- **巡回方法の列には `scripts/crawl.js` のパーサ名を書く**（例: `cfa-cards`）。
  `crawl.js` は状態が「巡回中」の行だけを巡回する。新しい構造の源を足すときは
  パーサを1つ実装し、その名前をこの列に書く。

## 各源の補足（URL確定時に埋める）

- **こども家庭庁**: ✅ P1で確定（2026-08-16）。`/news` を**全カテゴリ**で監視する [DECISION]。
  カテゴリ（報道発表・政策・法令等の10種）は機械では絞らず、項目にカテゴリ名を保存して
  P2の重要度判定に渡す（機械で絞ると例外を永久に取りこぼすため。絞りたくなったらP2側で調整）。
  RSSなし・静的HTML・robots.txt許可済み。巡回方法 `cfa-cards` は `scripts/crawl.js` のパーサ名。
- **厚生労働省**: 障害・介護分野の一次情報源。対象ページの粒度を確定する。
- **WAM NET**: 行政情報の集約先。一次情報への導線として使うか、それ自体を監視するかを判断する。
- **福岡県**: 法人所在地の自治体情報（福智町・県）。市町村レベルまで広げるかを判断する。
- **報酬改定関連**: 報酬改定ナビ（kanda-houtokukai/houshu-navi）と情報源が重なる可能性がある。
  重複監視にならないよう、houshu-navi 側の扱いと突き合わせる。
