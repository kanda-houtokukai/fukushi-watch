# 制度の原本リンク台帳（genpon-links.md）

サイド欄「制度の原本」リンク箱の**正本**（P41区切り③のD）。
ダッシュボード（index.html）が起動時にこのファイルを取得し、下の表の行をそのまま描画する。
**リンクの追加・削除・差し替えはこの表の行を編集するだけ**（コードは触らない・★★の教訓）。

## 運用ルール

- 掲載するのは「蓄積して参照される」制度文書の集約ページ（原本への入口）のみ。
  新着で流れる情報は紙面が、締切のあるものは助成・研修面が担当（住み分け）。
- **URLは掲載前に必ず生存確認する**（鉄則5）。年度付きURL（集団指導等）は年度替わりで差し替え。
- 備考列は台帳向けのメモで、画面には出さない。
- ⚠️2026-08-26時点の見送り: 福岡県の集団指導（介護保険）ページは令和7年度分が404
  （年度替わりで撤去された模様）。令和8年度ページが出たら行を足す。
